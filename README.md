# 手旗信号 3D トレーナー（ボーイスカウト向け）

Three.js 製のボーイスカウト日本連盟方式・和文手旗信号 3D トレーニングアプリです。  
外部サーバーやインターネット接続なしでも動作する **単体HTML版（`dist/index.html`）** と、開発用のモジュラーソース（`src/`）を含んでいます。

## 主な機能

- **🎯 自動トレーニングモード**
  - カタカナ基本46文字、1画8文字、濁音・半濁音、数字（0〜999）、ランダム3/5文字、スカウト用語、短文電報、苦手克服から自動出題
  - テキスト入力（ひらがな・カタカナ・数字自動正規化）と4択ボタン回答の両対応
  - 苦手文字の自動トラッキング＆復習機能
- **⚡ 超高速対応スピード調整（10 〜 400 字/分）**
  - スライダーおよびワンタッチプリセット（`激遅 15` / `初級 30` / `標準 55` / `高速 90` / `爆速 150` / `鬼速 240` / `神速 360`、最大 `400 字/分`）
  - 0.5xスロー再生・一時停止・再送対応
- **📖 教えるモード**
  - **基本原画**: 原姿・1〜14原画・逆2 の3Dモデル表示、旗の構え方ガイド、ミニSVG図解（第11原画「ク」の体の前を通る袈裟斬り軌道にも対応）
  - **50音分解**: 1コマずつ止めながらの打ち方確認＆連続実演
  - **交信符号**: 起信・応信・終信・解信・消信の動作とルール解説
  - **特訓コース**: レベル別グループ連続実演
- **🚩 自由送信モード**
  - 任意の日本語・数字を入力してリアルタイムに手旗変換・送信実演（起信/終信の自動付与・ループ再生対応）
- **🎥 3Dステージ表示オプション**
  - 視点切替（`正面(受信)` / `背面(送信)` / `斜め3D` ＋ マウス/タッチ自由回転）
  - `軌跡 ON/OFF`・`角度ガイド ON/OFF`・`帽子切替（ベレー / キャンプ帽 / なし）`・`音 ON/OFF`

## すぐ使う方法（単体HTML版）

リポジトリ内の [`dist/index.html`](./dist/index.html) をダウンロードし、Chrome / Edge / Safari などのブラウザでそのまま開くだけで動作します（ビルド済みのためインストール不要）。

## 開発・ビルド方法

```bash
npm install
npm run build
```

`scripts/build.mjs`（esbuild）により `src/` と Three.js を単一 HTML（`dist/index.html`）へバンドルします。

ローカルHTTPサーバーで確認したい場合：

```bash
npx serve .
# または python3 -m http.server 8080
```
